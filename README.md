# 🕵️ Deepfake Detection using EfficientNet-B3

## 📌 Project Overview
Deepfake detection is crucial for identifying AI-generated images and videos. This project leverages a **deep learning model (EfficientNet-B3)** trained on a balanced dataset of real and AI-generated fake images. The model achieves **98.61% accuracy** in classifying real vs. fake images, with a particular focus on detecting faces generated by *This Person Does Not Exist* and *Stable Diffusion*.

---

## 📂 Dataset Details
The dataset consists of real and fake images collected from multiple sources, ensuring a robust training process.

### **Sources of Fake Images**:
- **IEEE Published Dataset** (20k images)
- **This Person Does Not Exist** (20k images)
- **LivePortrait GitHub** (Animated fake images from real dataset)
- **Stable Diffusion AI**

### **Dataset Distribution**:
| Set          | Total Images | Fake | Real |
|-------------|-------------|------|------|
| **Train**   | 90,111      | 45,443 | 44,668 |
| **Validation** | 9,676     | 4,824 | 4,852 |
| **Test**    | 9,685       | 4,826 | 4,859 |
| **Total**   | 109,472     | 54,909 | 54,563 |

## 📊 Model Training

### **🛠 Model Architecture**
- **Backbone:** EfficientNet-B3
- **Pretrained Weights:** ImageNet
- **Final Layer:** Fully connected, **1 neuron (Sigmoid Activation)**
- **Loss Function:** Binary Cross-Entropy (BCEWithLogitsLoss)
- **Optimizer:** AdamW (learning rate = 0.0001, weight decay = 1e-4)
- **Learning Rate Scheduler:** CosineAnnealingLR
- **Training Enhancements:** Mixed Precision Training, Random Erasing, Data Augmentation

### **📈 Training Performance**
- **Train Loss:** `0.071`  
- **Train Accuracy:** `97.40%`  
- **Validation Loss:** `0.042`  
- **Validation Accuracy:** `98.46%`  
- **Test Loss:** `0.037`  
- **Test Accuracy:** `98.61%`  

### **Classification Report**
| Class  | Precision | Recall | F1-Score | Support |
|--------|------------|--------|------------|---------|
| **Fake** | 0.98 | 0.99 | 0.99 | 4826 |
| **Real** | 0.99 | 0.98 | 0.99 | 4826 |
| **Overall Accuracy** | **0.99** | **0.99** | **0.99** | **9652** |

## 🚀 Web App Deployment

### **🖥 Features:**
✔️ Upload **images (JPG, PNG)** for deepfake detection  
✔️ Upload **videos (MP4, AVI)** and extract frames for analysis  
✔️ **Real-time deepfake classification** using EfficientNet-B3  
✔️ **Flask API for integration with other applications**  

### **1️⃣ Clone the Repository**
```bash
git clone https://github.com/AmarSingh-11/deepfake-detection.git
cd deepfake-detection
```

### **2️⃣ Install Dependencies**
```bash
pip install -r requirements.txt
```

### **3️⃣ Run the Web App**
```bash
python app.py
```
The application will be available at **`http://localhost:5000/`**.

## 🔗 API Endpoints
### **1️⃣ Detect Deepfake in Image**
#### **Endpoint:**
```http
POST /DetectImage
```
#### **Usage:**
```python
import requests
files = {"file": open("test_image.jpg", "rb")}
response = requests.post("http://localhost:5000/DetectImage", files=files)
print(response.json())
```

### **2️⃣ Detect Deepfake in Video**
#### **Endpoint:**
```http

import requests

response = requests.post("http://localhost:5000/Detect", files=files)

```
